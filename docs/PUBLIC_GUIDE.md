# Using AlterEcho

AlterEcho helps you ask a precise question: does a particular Earth window have terrain distributions similar to a particular window on Mars? Choose a reference, choose Terrain analogy, then select an Earth site. Open the paired images to inspect the actual study windows and use Full evidence to see how the result was calculated.

The experimental index runs from 0 to 100. It is not a percentage likeness to Mars or a probability. Many smooth Earth landscapes score highly, so read the background share, measured differences and tie group alongside it. Two sites in the same tie group have an ordering that the tested scenarios do not resolve.

Evidence coverage tells you how much of the selected question's planned evidence has comparable measurements. A complete terrain profile can still say nothing about minerals, temperatures, water, life, soil strength, construction or safety. Other profiles remain partial or not assessed; they do not receive an overall score when critical evidence is missing.

Satellite pictures help you inspect the site. They do not generate the terrain score. The score comes from elevation models processed in Python. Each result offers source records, acquisition metadata and a JSON export; the Sources page also provides the machine-readable audit. Light, Dark and System themes preserve the scientific image pixels.

Five Mars reference windows are processed. The lunar south-pole window currently shows measured distances without an index because moving the reference changes the result too much relative to the method's tolerance. Holuhraun and McMurdo remain planned. The original Atacama window is excluded because it contains industrial terrain.

Use Explore an area for a preliminary Earth terrain screen. A failed download or missing credential is shown explicitly, and a new screening result is not automatically added to the atlas. AlterEcho is a research prototype, not a landing-site, base-siting or field-safety recommendation.
